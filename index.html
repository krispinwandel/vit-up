Dense ViT-Up features on video. DINOv3-S+ with a 56×56 backbone grid, queried at every pixel of each frame and projected to RGB with one PCA per clip.

Overview

Image-guided feature upsamplers produce visually sharp features, but their shallow image encoders can introduce feature leakage, fragmentation and blur.

ViT-Up is an implicit feature upsampler for Vision Transformers that builds its queries from intermediate ViT hidden states instead. It predicts features at arbitrary continuous image coordinates while preserving alignment with the backbone feature space.

On DINOv3-S+, ViT-Up improves over the strongest baselines by +3.08 mIoU in linear probing on Cityscapes, +5.12 PCK@0.10 in semantic correspondence on SPair-71k and +5.7 J&F in video object segmentation on DAVIS-2017 (k-NN label propagation).

Quick start · Python
import torch
from PIL import Image

model = torch.hub.load(
    "krispinwandel/vit-up",
    "vit_up_dinov3_splus",
    trust_repo=True,
)

# 1. Encode the image once.
model.set_images(Image.open("image.png").convert("RGB"))

# 2. Query features at any (x, y) in [0, 1].
points = torch.tensor([[[0.25, 0.50], [0.70, 0.33]]])
features = model(query_coords=points)     # (B, N, C)

# ...or on a dense grid at any resolution.
dense = model.dense(output_size=896)      # (B, 896, 896, C)

Method

ViT-Up replaces external image guidance with layer-wise query construction from intermediate ViT hidden states, and is trained in two stages.

Training stages

Stage 1

Multi-scale feature supervision

Distills features from a frozen teacher at multiple resolutions, with LoRA adapting the backbone.

Stage 2

Offset-guided refinement

Self-distillation from the frozen Stage 1 model with learned query offsets, for increased sharpness and detail.

Results

ViT-Up consistently outperforms state-of-the-art image-guided upsamplers in dense linear probing, semantic correspondence and video object segmentation.

Qualitative comparison

PCA of the dense features (top rows) and similarity to a query point (bottom rows) on a 448×448 input with a native 28×28 backbone grid. ViT-Up gives coherent structure and selective similarity maps; NAF, AnyUp and JAFAR look sharp but fragment and leak into nearby structures, and UpLiFT is smoother but weaker on small regions.
